# Mira Vale — Signal / Matter

A dependency-free, single-page portfolio for Mira Vale, an invented creative technologist and interface artist.

## Direction

The visual language is a retro-futurist field journal / space observatory: oversized editorial typography, orbital diagrams, acid coral, electric cyan, violet signal graphics, mono annotations, and subtle film grain.

## Run locally

Open `index.html` directly in a modern browser. No build step, package manager, server, or framework is required.

## Features

- Semantic single-page HTML with anchored navigation
- Responsive CSS Grid and Flexbox layouts
- Scroll reveal using `IntersectionObserver`
- Active navigation state based on the visible section
- Persistent dark/light theme switcher
- Persistent English/Arabic language switcher with RTL support
- Client-side accessible contact form validation
- Reduced-motion support
- Google Fonts loaded remotely for Space Grotesk, IBM Plex Mono, and Cairo
